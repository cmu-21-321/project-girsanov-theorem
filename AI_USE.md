# AI-use statement

Parts of this project were developed with the help of AI assistants (Claude by Anthropic).
As a team, we used them to:

- explain background mathematics and Lean/Mathlib concepts,
- search Mathlib for relevant lemmas and check their current names and signatures,
- draft Lean definitions, statements, proofs and documentation, and
- help with project setup and tooling (Lean, Lake, git).

Every definition and theorem statement in this repository was reviewed by a team member to
confirm it says what we intend, and every proof is checked by Lean: the project builds with
`lake build`, so no result depends on trusting an AI's output. Each member's use is described
below, with the files, definitions and theorems where AI-generated code remains.

## Farin Weinger

**Tools.** Claude (Anthropic) in the Claude app, and Claude Code run in the project folder.
Model: Claude Opus 5.5.

**Explanations, setup and library search.**
- Explanations of the finite-dimensional Girsanov theorem, Lean syntax (namespaces, `open`,
  `abbrev` vs `def`, instances) and the Bochner vs. lower Lebesgue integral in Mathlib.
- Step-by-step help with Lean, Lake, VS Code and git, and diagnosis of the duplicate
  `girsanov/` folder that broke CI.
- Initial searches of the Mathlib source for the lemma names in the Step · Fact · Mathlib
  name lists of `Girsanov/DensityTransfer.lean` and `Girsanov/FiniteTime.lean`, which I
  confirmed with `#check`.

**Definitions (drafted by AI, reviewed and improved upon by me).**
- `Girsanov/Basic.lean`: `tiltWeight`, `canonicalDensity` (as a product of `tiltWeight`s)
  and `incrementLaw` (as an `abbrev`). After course-staff feedback on our definitions,
  Claude proposed this design and drafted the Lean code; I checked each definition against
  the mathematics, tested it with API lemmas, and adopted it.
- The statement of `pi_withDensity` in `Girsanov/DensityTransfer.lean`, including the change
  from a σ-finiteness instance to the hypothesis `hf_top`.

**Statements and proofs generated by AI at my direction.** I specified the tasks, constraints
and proof plans, and reviewed each result.
- `Girsanov/DensityTransfer.lean`: `pi_withDensity` and the private helper
  `indicator_univ_pi_prod`.
- `Girsanov/FiniteTime.lean`: `map_increments_eq_pi`, `incrementLaw_withDensity`,
  `prod_tiltWeight`, `girsanov_gaussian_pi`, `girsanov_increments`, and the `n = 1` example.
- `Girsanov/Basic.lean`: proofs of `measurable_tiltWeight`, `tiltWeight_pos`,
  `measurable_canonicalDensity`, `canonicalDensity_eq_exp_sum` and
  `girsanovDensity_eq_canonicalDensity_comp`.
- `Girsanov/SingleTime.lean`: the proof of `map_withDensity_comp` (commit `8cda85f`).
- The change to real-valued densities in commit `8cda85f`, across `Basic.lean`,
  `DensityTransfer.lean`, `FiniteTime.lean`, `GaussianTilt.lean` and `SingleTime.lean`.
- Comments and docstrings in my sections, rewritten in ASD-STE100 style.

**Report and video.**
- Claude drafted the LaTeX outline and some sections of the report. I directed the content and structure and revised the text sentence by sentence.
- Claude checked the video slides against the code for accuracy.
